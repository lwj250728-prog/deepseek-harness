# DSH Mobile — Android client (WebView shell)

English | [中文](README.zh.md)

The Android "app": a minimal WebView shell (Kotlin, **zero third-party
dependencies**) that works with the [dsh-mobile-gateway](../) plugin. After
installing the APK, the app logs into the gateway automatically with the
saved user name + access token, then loads the DSH Web GUI fullscreen.

## Features

- First launch shows a setup screen: gateway address, optional user name, access token, and a "trust self-signed certificate" switch.
- The token is encrypted with the **Android Keystore (AES/GCM)** — never plaintext in SharedPreferences.
- Automatically POSTs `/__mobile/login`; the session cookie lands in the WebView cookie manager, then the UI loads.
- A 401/403 while browsing (token rotated/removed) bounces back to the setup screen for a fresh token.
- Menu "Switch account": clears cookies + credentials and returns to setup.
- Back button walks WebView history; same-gateway URLs stay in-app, external links go to the system browser.

## Build (needs the Android SDK)

1. Open this directory (`android/`) in Android Studio, or from the command line:

   ```sh
   # Requires Android SDK 34 (set ANDROID_HOME)
   cd android
   ./gradlew assembleDebug        # Windows: gradlew.bat assembleDebug
   # Output: app/build/outputs/apk/debug/app-debug.apk
   ```

2. Install the APK on the phone (`adb install app-debug.apk` or copy it over).
3. Open the app and enter the gateway address (`http://<PC-IP>:4080`) plus the token issued by the admin.

## Notes

- Project config: `compileSdk 34 / targetSdk 34 / minSdk 24 / Kotlin 1.9.24 / AGP 8.5.2`.
- `usesCleartextTraffic="true"` is required for the plain-HTTP LAN gateway; drop it if the gateway serves HTTPS.
- Self-signed certificates are rejected unless the setup switch is checked explicitly (MITM defense).
- Launcher icons live in `app/src/main/res/mipmap-*/` (generated by script).
