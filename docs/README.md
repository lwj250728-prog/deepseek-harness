## 核心架构速览

```
热环路 (在线):  输入 → SAR提取 → OOD检测 → 5层校准 → 预测
冷环路 (离线):  误差>40% → 效用聚类 → 因果锚定 → 沙盒验证 → 回写
探索环路 (空闲): 每日预算 → 高误差识别 → ROI追踪 → 元学习
```

## 关键设计原则

1. **效用优先于语义** — 按"行动-结果"的因果效用聚类，而非文本相似度
2. **预测误差驱动重建** — 不因数量堆积，只因"猜错了"才推倒
3. **双环路解耦** — 热环路毫秒级，冷环路深度计算
4. **置信度校准** — 五层防护对抗LLM过度自信
