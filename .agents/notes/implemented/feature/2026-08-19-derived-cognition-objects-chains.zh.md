# Agent Note: 派生认知对象与目标锚定经验链

Status: implemented

[English](2026-08-19-derived-cognition-objects-chains.md) | 中文

## 问题

此前构建的每一层特殊经验——簇、元认知环路、验收准则、跳转词——都遵循同一个生命周期（从经验投影、带证据持久化、在反馈尺上度量、重建强化、模型可见暴露），但每一层都是手搓的。第五层（目标锚定链：把跨会话、跨 agent 的目标执行聚合为因果骨架）即将以同样方式建造，而这个重复出现的形态又要一次不点名地重复。同时，短情景经验没有容纳跨会话、跨 agent 结构的位置：exp_73 显示委派轮次会丢失（孤儿场景），exp_108 的视角覆盖只作用于单条经验粒度。

## 决策

三件事一起落地：

**1. 派生认知对象抽象**（`src/cognition-objects.ts` 的 `CognitionObjectKind`）：一个种类声明其生命周期——`project`（存储 → 候选构建，带证据闸）、`persist`、`measure`（把反馈折入该对象的尺子）、`reinforce`（携带统计、应用闸门）、`expose`（当前对象）。服务持有注册表（`registerCognitionObject`/`cognitionObjects`）与通用驱动（`rebuildCognitionObject`），驱动任意种类走完生命周期。抽象只覆盖决策层：存储、通道接线与 legacy 归一化仍按种类实现（exp_93 的边界教训——通用抽象不能变成包在逐种类执行外的脆包装）。存量四层不强行迁移；它们非正式符合该形态，可增量声明为种类。

**2. 目标锚定链作为首个声明式种类**（`chain`）：经验新增可选 `chainId`/`parentNodeId`/`sequence` 标签（加载时 legacy 归一化）；`chains.json` 持久化巩固后的 `ChainExperience`。`consolidate_chain`（或通用驱动）从带标签成员组装因果骨架：失败步与跨 agent 委派节点（回执）保持结构步，例行成功步坍缩为有界摘要（记忆组织在惊喜周围——Schank 的 MOP），链携带成员/委派 id、坍缩计数与上一条链的引用统计。引用环扩展到链：`recordInjection` 接受 `chainId`，`settleInjectionCitations` 把链级结果（轮次文本引用链即 cited）折回链的 hit/cited 账本。`chainExpose` 把链渲染为结构化步骤供注入路径使用。链构成**目标树**：委派子目标的链挂在委派链之下（其根成员引用父链回执），在巩固/投影时派生为 `childChainIds`；`chainChildren`/`chainTreeExpose` 暴露子树以支持目标结构化扩散——命中父链时可下钻到子目标结果。

**3. 链模式作为该抽象的首个递归消费者**（`chain-pattern`）：模式从链表投影，正如链从经验投影。共享结构签名（粗粒度目标域 + 步极性序列，如 `发布:失败,失败,成功`）的链聚合为一种周期性目标执行模式（TOPS 类比：从相似 MOP 提炼跨情境主题模式），由 `chainPatternMinMembers` 闸门把关，持久化于 `chain_patterns.json`。度量效用从成员链的引用统计聚合：链模式种类的 `measure` 由同一 `settleInjectionCitations` 折叠分派，因此模式的引用率可追溯地度量分组是否有用。

## 备选方案

**不抽抽象直接建链。** 否决：生命周期形态已重复四次；第五个手搓实例是重复一个已可识别的模式。相对通用驱动，一次声明约 30 行。

**链模式写成定制逻辑。** 否决：递归（模式从链投影，正如链从经验投影）正是该抽象存在的意义——第六个种类只花了一次声明加一张存储表，其 measure 步复用同一个折叠分派。

**现在就强制把存量四层迁移到抽象上。** 否决（exp_93 边界）：抽象不能变成包在逐种类执行外的脆包装——存储表、legacy 归一化、通道接线都不同。声明式是增量的。

**链 = 最近 N 轮线性列表（无目标标签）。** 否决：事件分割说链在目标/状态跃迁处切断，而非固定间隔；chainId 标签（由 orchestrator 传播或显式设置的目标追踪号）是粘合胶。

## 后果

- 十五个模型工具（原十四）；第六张持久化表（`chain_patterns.json`，外加 `chains.json`）；注入引用环现在也度量链级与模式级效用。
- 链是带标签原子的**派生视图**：原子在线积累、链离线巩固（目标完成/agent 空闲——系统巩固的工程对应）。没有标签的链永远不成形。remember 工具路径现已携带标签（`remember_experience` 接受 `chain_id` 目标追踪号），执行目标的调用方可随记随标——闭合了 exp_73 缺口（未打标签的通道产生孤儿场景）。对于**从未打标签**的原子，`explore_chain` 改为从文本恢复目标结构：按 outcome→situation 承接建议上下游邻居（永不写入），因此散落的经验库仍可被调用方打标签并巩固为链。仍不打标签的通道继续产生孤儿场景；抽象不修未打链的通道，它命名缺口并提供恢复工具。模式继承该依赖：它们只聚合实际成形的链。
- 子链检测锚定在链的**根成员**引用父链回执上，从而打破共享回执本会造成的循环（携带同一回执的中段委派节点的链不会成为它自己的子链）。
- 通用驱动意味着第七个及以后的派生对象只需一次声明，而非管线式手搓。
