# Agent Note：驱动力机制——方差账本、失衡门与变体候选

Status: implemented

[English](2026-08-19-driving-force-mechanisms.md) | 中文

## 问题

[SAR 机制原理审视](../../proposed/architecture/2026-08-19-sar-principle-review.md)发现管线把所有异常都同化为噪声：`outcomeUtility` 是单点自述，预测误差只记账，没有任何机制会问"已记录的步骤能否改进"。其驱动力框架要求四个机制——方差感知、失衡检测、变体生成、迭代收敛——动机锚定在任务流（不满足感）与结算流（方差）上，绝不发明目标。

## 决策

四个机制中的三个作为一条链落地在既有库上，每个机制消费前一个的输出。

**1. 结算方差账本。** `Experience.settlements` 在每次携带结果质量的预测结算时追加一个原始质量样本（`SettlementSample{ts, quality}`）。样本上的分布就是方差度量；单点效用标签保持不动，仍是聚类输入。采样保守：无质量的结算从不追加，账本只容纳真实执行结果。

**2. 失衡门。** `disequilibriumOf` 把新样本与既有分布比较：`z = |q − μ|/σ`，先验样本 ≥ `disequilibriumMinSamples`（默认 3）且 `z ≥ disequilibriumZThreshold`（默认 2）时，经验被标记 `DisequilibriumEvent{atTs, sampleQuality, zScore}`。退化先验（σ = 0）永不判定。该门是默认同化的显式替代：被标记的经验是顺应候选，不是噪声归因。两个阈值都是热引擎上经校验的配置字段。

**3. 变体候选。** `generateStrategyVariants(strategyId)` 对偏离门触发策略的行动、验收锚点与前置校验运行模板 8 的 LLM 路由，产出至多三个 `VariantCandidate`，扰动单一环节或参数且锚点语义不变——锚点是测试，变体是修订后的流程。候选以 `proposed` 状态进入 `variants` 表，并携带结算列表供迭代收敛机制（机制 4，尚未实现）使用。无显式路由时生成确定性返回零候选：无模型，无编造的变体。触发接线：`settleInjectionCitations` 折叠策略使用，新触发的 `reworkNeeded`（此前干净、现在触发）以尽力而为方式触发生成，try/catch 包裹，生成失败绝不破坏结算。

inspect 聚合（`InspectResult.settlement` + `variants`）暴露账本覆盖率与候选生命周期计数；`inspect_memory` 工具 schema 携带它们。

## 备选方案

**无路由时确定性生成变体。** 否决：确定性生成器要么模板化改写（无价值，prompt 显式禁止纯改写），要么无模型判断地编造扰动。空降级保持了管线"尽力而为优于安全回退"的契约。

**把生成接到经验级失衡标记上。** 暂缓：经验不携带验收锚点，变体没有可机器核验的测试。策略级锚点（已是漂移传感器）是今天唯一"变体成功"可机械判定的地方。经验级顺应留待机制 4。

**保持一次性生命周期（探索 ROI）。** 否决：机制 3 只开门；候选的结算列表是为机制 4 需要的多轮收敛准备的显式钩子。现在建账本，收敛门在落地当天就有数据。

## 后果

- 管线现在能感知结果方差（机制 1）、检测分布偏移（机制 2）、为失效策略生成结构化修订（机制 3）——种田类比的顺应一半不再结构性缺失。
- 每个携带质量的真实 `predict → report` 循环都喂账本；首笔活样本在真实会话中从一次真实预测落到 `exp_121`。
- 固化策略的偏离门获得行动：越过 `reworkNeeded` 现在生成候选，而非静默标记。
- 成本：一张新表（`variants.json`）、一个 prompt 模板（模板 8）、三个配置字段，以及两个新形态的不变式检查。触发按设计依赖 LLM 路由——无路由的部署中偏离只标记不生成，这是安全降级。
