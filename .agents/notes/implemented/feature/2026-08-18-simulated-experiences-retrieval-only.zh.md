# Agent Note：模拟经验——仅检索候选与现实监控退出

Status: implemented

[English](2026-08-18-simulated-experiences-retrieval-only.md) | 中文

## 问题

冷环在真实存储上正确地暂缓了：带标签验证门槛（见 [冷环验收](2026-08-18-cold-loop-acceptance-first-build-and-deferral.md)）在带真实标签的经验太少时拒绝聚簇。但暂缓不等于进展。冷启动时经验库的已验证样本太少，无法聚类、检索、预测——而等待更多样本是被动的答案。人类不等待：直接测试便宜又安全时大量试；条件不允许时从相似情境类比推理或心理模拟。认知流水线没有第三条路径的对应物——基于模型的模拟——而它现有的探索通道（临时工作区）只在模型恰好再次预测同一行动时才复用。

## 决策

**模拟经验以 `simulated` 标记进入存储，作为仅检索候选。** 它们由 LLM 路由生成（给定情境与拟采取行动，产出预测结果与临时效用），以 `simulated: true` 存储，对检索、预测参照与 orchestrator 注入可见——但永不进入冷环聚类。模拟经验不塑造任何簇质心、不进入任何分类法规则；只有真实、已验证的反馈能解锁聚类资格。这是设计所模仿的认知科学分层。

**分层镜像人类记忆。** 现实监控（Johnson & Raye）区分真实经历与想象内容——`simulated` 标记即机器对应物。固化只对真实的经历——心理模拟的方案不进入把经历压缩为稳定知识的睡眠重放固化通道；冷环即该通道，模拟经验不进入。模拟提供假设空间，而非公认知识——模拟样本喂检索与预测参照，但在验证前不被当作稳定策略。

**模拟经验通过三条通道离开存储，全部由一条原则驱动——证据替代。** 其生命周期完全由真实证据驱动：证据足够则升级，证据覆盖则降权走向过期，证据矛盾则回滚。天数、反馈次数、置信度分数都是这条原则在不同信号通道上的代理；它们本身都不是规则。

1. **被真实反馈验证**——`report_outcome` 对绑定到模拟经验的预测，把反馈的证据权重计入 `evidenceScore`。单次决定性权重 ≥ `simulationFastTrackThreshold` 快速晋升为 `provisional`；累计证据 ≥ `simulationPermanentThreshold` 升级为 `verified`。临时态遇矛盾反馈回滚为 `unverified` 并重置分数。
2. **被真实证据替代（主通道）**——同情境的已验证经验使其降权并最终过期，镜像"真做过后心理预演不留痕"。
3. **验证超时（仅兜底）**——在 `simulationTtlMs`（默认 30 天）内既无反馈也未被替代的未验证模拟过期并从检索移除。

**聚类资格是唯一门，由累计证据而非命中次数驱动。** 升级条件是 `Σ feedback_i 的置信度权重 w_i ≥ simulationPermanentThreshold`；每次反馈贡献一个由质量决定性推导的权重。三次一致的中等置信度反馈可以跨过阈值；一次决定性的高置信度反馈也可以。快速通道授予临时而非永久资格——校准的告诫是真实的，后续矛盾即回滚。

**已交付的表面：** `Experience` 新增 `simulated: boolean`、`verification: 'unverified' | 'provisional' | 'verified'` 与 `evidenceScore: number`（普通 `remember_experience` 写入自出生即 `verified`）。新 `simulate_experience` 工具与 `ctx.cognitivePipeline.simulate()` 经 LLM 路由生成模拟经验。检索（`retrieveTopK`、orchestrator `retrieve()`、inject 预热）包含模拟样本；冷环 `sample()` 排除未验证者。`report_outcome` 对绑定的模拟经验驱动证据替代状态机，并同时把质量回填为效用标签。

## 备选方案

**模拟样本从一开始就参与聚类。** 否决：那会让未经验证的推断塑造簇质心与分类法规则——正是冷环带标签验证门槛要防止的污染，从后门重新引入。

**模拟样本留在独立池，验证后才合并。** 否决：独立池复制了存储的持久化、检索与生命周期机制；共享存储上的 `simulated` 标记加聚类排除，以单一权威达成同样的隔离（遵循[反馈回填 note](2026-08-18-feedback-folds-result-quality-into-experience-label.md)的"单一标签源"规则）。

**仅靠验证与密度，无兜底超时。** 否决：某个模拟可能永远等不到真实反馈，且孤立情境的密度可能永远达不到替代阈值；无后备则存储积累过期的未验证推断。长兜底 TTL 守护这一角落。

## 后果

模拟经验可检索、可注入，但绝不出现于簇、分类法规则或冷环采样中；只有 verified 或 provisional 样本可塑造簇。真实反馈按证据规则升级——累计证据跨过阈值 → 永久 `verified`；单次决定性反馈 → 临时 `verified` 带观察窗口，矛盾时回滚——此后参与聚类。同情境已验证密度使其降权并过期；兜底 TTL 守护"永不到来"的情形。冷启动路径现已激活：真实标签稀缺时，模型可生成理性推演来辅助预测而不污染分类法，证据替代生命周期让存储免于过期的未验证推断。包测试、typecheck、lint 与文档门禁全绿；`simulate_experience` 工具表面由 loader 与 pipeline 测试覆盖，状态机由 store 测试覆盖，冷环排除由专门的重建测试覆盖。

## 风险

- **模拟质量漂移**：LLM 生成的结果可能系统性乐观。以 verified 门缓解（只有真实反馈升级），且模拟样本只是检索候选——它们建议，不断言。
- **检索噪声**：标签稀缺时模拟候选可能先于已验证样本浮现。接受——这正是冷启动的预期行为；随标签积累，已验证样本将其挤出。
- **验证永不到来**：兜底 TTL 使模拟经验过期；存储不积累过期的未验证推断。
- **密度信号敏感性**：替代模拟的"已验证密度"阈值本身是代理；以同样的证据强度框架调参，而非魔法常数。
