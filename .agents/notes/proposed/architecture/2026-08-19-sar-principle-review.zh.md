# Agent Note：SAR 机制原理审视——预测误差是注意触发器，不是编码过滤器

Status: proposed

[English](2026-08-19-sar-principle-review.md) | 中文

## 问题

DCA-PED 的立论是经验通过预测误差积累：热环（predict/report，|校准−观测|）学习，冷环（`rebuild_taxonomy`）对高误差经验重新聚簇，两者都被认为是"哪些经验重要"的驱动。三条实测事实与这一立论相矛盾。

其一，预测覆盖率仅 6.2%。195 条经验中只有 12 条绑定 prediction expId。主积累路径——`remember_experience` 与 `accumulateTurn`——编码并存储时不经过任何预测步骤：出生即 `predictionError: null, cumulativeError: 0`。预测误差只能经 `resolvePrediction` 到达经验，而它要求绑定 predictionId。"预测误差驱动积累"因此只对库中 6.2% 成立；93.8% 是 LLM 门驱动积累。

其二，校准误差的下降可能是收缩而非进步。平均校准概率 0.563、跨度 0.22；五层校准器把预测拉向中间值。|校准−观测| 于是因预测变得更模糊而下降，不是因为预测变得更准。单一指标无法区分可靠性提升与分辨率丧失（Brier 分解）。

其三，误差不预测价值。exp_8 累计误差 0.67，却从未被注入；exp_25 累计误差 0.15，也从未被注入。195 条经验中只有 26 条曾被注入、8 条曾被引用。误差大小与"决策是否采纳一条经验"正交。

第一性原理审视解释了原因：SAR 声称与实际实现之间存在六个结构性错位。

**A. 编码没有期望字段。** Schank 的期望失败与 Friston 的自由能都把意外（surprise）作为记忆更新的触发器。SAR 模式（情境/行动/结果/效用）没有"预测结果"或"期望结果"字段。`extractSar` 拆分文本并标注效用；它从不记录行动者原本期望什么。编码时刻不存在意外信号，积累因此是无差别的。

**B. 主路径从不经过闭环。** `accumulateTurn` 以 LLM 判断（值得记吗？）为门，与任何预测无关。在 predict/report 闭环之外出生的经验永远无法累积 predictionError，冷环的误差优先采样因此永远不会把它们视为有误差。

**C. 效用是自述，不是实测。** `outcomeUtility` 是 LLM 编码时刻的自我评估。聚类轴是对这一自我评估的哈希，头部加权 ×4。`resolvePrediction` 回填 materialGain = 5 + (q−5)·0.8，但只对那 12 条绑定经验生效。聚簇因此聚的是"模型声称的感受"，不是"实际起效的东西"。自述效用是假设，永远不是事实。

**D. 误差是注意触发器，不是价值度量。** 高误差有两种成因：情境是不可预测的噪声（无可学），或模型缺少经验（值得学）。误差大小无法区分二者。冷环对高误差经验采样聚簇，于是噪声可以塑造聚簇，而真正被采纳的低误差经验永远不加入。

**E. 情境维度没有表征。** 检索轴是 `actionVector(行动+关键词)`；聚类轴是 `outcomeVector(效用+结果文本)`。情境不是一个轴：`situationCentroid` 由 `actionVector(exp.sar.situation)` 构建，`taxonomyContext` 同样计算 `actionVector(situation)`。"同情境、不同行动"与"不同情境、同行动"在向量空间中不可区分。

**F. 经验是永不演化的快照。** 写入后，经验只经误差/效用回填改变。`hitCount` 在簇匹配时累加，但从不进入检索排序、聚类轴或任何保留决策。没有巩固也没有遗忘——这正是自持目标需要补上的。

## 提案

审视的交付物是每个 SAR 元素的角色重定位，作为未来每个自持机制的设计约束。这里不设计任何机制；约束集就是闸门。

| 元素 | 当前角色 | 正确角色 |
| --- | --- | --- |
| 情境 | 塞进行动向量器 | 情境识别："这是哪类事件"，自有轴 |
| 行动 | 检索轴（哈希文本） | 行为候选：可迁移的策略 |
| 结果 | 聚类尾部文本 | 结算证据：事后验证 |
| 预测误差 | 聚类采样信号 | 注意触发器："模型这里需要更新"，永非价值度量 |
| 结果效用 | 聚类头部，×4 | 初始假设，待机器可核验的验证 |
| 引用 / 采纳 | 不作为信号追踪 | 真正的价值信号：决策采纳该经验的次数 |
| 簇 | 结果效用分组 | 行为模式：迁移单元 |

自持设计的六条约束：

1. **编码门控使用"与既有记忆的预测差距"，而非 LLM 自述的意外。** 门是"该事件距既往经验的预测有多远"，这要求编码时刻存在期望。
2. **价值信号从自述效用切换到机器可核验的引用。** 与外部见证哲学（log/file/command 锚点）一致：采纳计数，而非感受效用。
3. **误差触发对既有记忆的重估，而非新建经验。** Bartlett：意外修订图式。经验上的高误差应更新、合并或回滚该记忆，而非复制出一条新经验。
4. **经验需要生命周期：强化、衰减、淘汰。** 这首先需要引用账本；没有它，保留决策就没有证据。
5. **聚类轴从效用模式迁移到行为模式加结果证据。** 聚簇成为以"做了什么 + 验证了什么"为键的策略迁移单元。
6. **情境获得独立表征。** 否则情境相似与行动相似持续混淆，情境驱动召回无法存在。

## 备选方案

**保留预测误差为工作机制，只扩大覆盖。** 否决：扩大覆盖让每条经验都经过 predict/report，但实测显示闭环本身放错了位置（B：主路径在环外；D：误差不等于价值）。覆盖买来的是更好的回测，不是更好的编码。

**用 TD 式价值模型（奖励替代效用）替换 SAR。** 否决：库的可用结构（链、簇、验收账本、注入记录）可复用；缺陷在价值信号，不在记忆容器。TD 重写会用同样的缺陷丢弃可用结构。

**完全弃用误差，只保留引用为信号。** 否决：误差仍是"预测哪里不可靠"的正确触发器，冷环对困难区域重新聚簇正需要它。修正方向是把误差从价值度量降级为注意触发器，而不是删除它。

## 验收标准

- 上述每条错位声明都能映射到 src/ 某行或可从 `data/cognitive-pipeline/` 复现的数据事实；本 Note 记录该映射。
- 三条实测事实（6.2% 覆盖、0.22 跨度、误差与引用正交）可从 JSONL 数据复算。
- 未来每个自持机制设计须就六条约束逐一说明：要么满足它，要么显式否决并说明理由。

## 风险

- **审视过度修正。** 既有机制（簇、链、验收准则、延迟结算）已被证明可用；本 Note 重定位 SAR 的价值层，并不否定经验库。约束 3 保留误差的用途。
- **引用导向的价值需要一个尚不存在的账本。** 约束 4 依赖它；账本是前提，不是副产品。
- **情境表征可能花费 token 或引入新接缝。** 约束 6 约束最弱；它可能在其他五条之后落地。
