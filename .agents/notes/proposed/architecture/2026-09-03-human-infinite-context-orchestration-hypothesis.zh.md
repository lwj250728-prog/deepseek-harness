# Agent Note: 人类的无限上下文以记忆的程序编排为地基——一条假设

Status: proposed

[English](2026-09-03-human-infinite-context-orchestration-hypothesis.md) | 中文

## 问题

数字生命路线承诺主对话经由认知管线与持续记忆近似无限上下文。仅靠工程无法支撑这个承诺："近无限上下文"目前是架构主张，而非被测过的属性。要设计正确的验收测试——并知道什么会让路线失败——路线需要一个显式模型，说明人类式无界连续究竟是什么。本注记把该模型**作为一条假设**记录，标注其认识论地位与证伪路径，以免工程把猜测悄悄当成事实。

## 方案

假设，精确表述如下：

> 人类式的无界连续，不是大工作窗口的产物，也不是存储容量的产物，而是记忆的程序编排的产物：编码什么、如何按线索提取、该忘什么、自我模型如何每步再固化。所谓"无限上下文"的感觉，是这些程序持续运行时产生的功能性错觉——连续性在每一刻由线索加重构重新生成，从不从存储回放。

支撑观察：工作记忆只容几个组块，注意力单通道，人从未"看见"自己的全部过去；但人能把一条线索延续几十年——说明连续性驻留在窗口之外，按需重算（Baddeley 的中央执行、Tulving 的编码/提取框架）。提取是建构而非档案回放（Bartlett）；遗忘是特性，防止噪声毒化此后每一次提取；每次回忆都会再固化（reconsolidation）它所触及的记忆。

映射到本路线已建成的器官，每类人类程序都有工程对应：编码选择 → auto-accumulate 的多重门控；按线索建构式提取 → 情境相似度检索 + 触发词/相似度/否决门 + 视角覆盖；遗忘/门控 → 注入冷却、任务复述拒绝、检索阈值；自我模型再固化 → 回合末自检推进情景链头 + 压缩写回；行动前受控回想要 → 预输入回顾子代理。

因此本路线"无限"的操作性定义在**提取侧而非存储侧**：完成任务所需的事实，放在任意久远的位置（哪怕已被压缩挤掉），当它变得相关时，必须由记忆程序归还——模型基于被想起的材料作答，无需运营者重述。

## 认识论地位

这是**模型级假设，不是关于大脑的经验断言**。认知科学对这些控制过程的神经实现至今没有定论（前额叶执行、海马索引、皮层重构都是竞争性假说）。与已建成器官的映射是工程类比，其价值由它是否产出正确的验收测试来评判，而非神经学真伪。

## 证伪路径

该假设对本实现可证伪：跑一段脚本化会话——埋入一条旧事实，跨过真实压缩边界，切换话题，再绕回提问；若主对话无法基于被想起的材料作答而需重述，则编排假设在该系统、该时程上失败。第二个探针是规模下的精度：经验库增长到数百条时，检索仍须命中相关项，门控仍须挡下噪声——是一条曲线，不是单点。这正是 M2 已欠下的两项验证（压缩写回活体证据；规模检索精度）。

## 备选方案

- **长窗口存储中心模型**：把无界上下文当作更大的窗口加更好的摘要。作为地基模型否决——它推迟边界而非解释连续性，其验收（"窗口能否装更多"）从不触及代理能否自主想起。
- **纯外部 RAG**：检索存储文档、无自我模型。否决——它捕获事实，却捕获不了那个必须被再固化的进行中的自我；本路线的链头回路正是缺失的那个程序。

## 验收标准

假设以其证伪路径被记录，并挂到路线的验证计划上：跨压缩边界的召回验收（M2）与规模检索精度探针，就是对本实现确认或推翻它的测试。

## 风险

主要风险是范畴错误：把假设当教义，让工程过度迎合类比（例如在保留更好的地方刻意引入遗忘，或假定检索建构必须像 Bartlett 那样失真）。本注记的状态行就是护栏——在验收测试给出别的结论之前，它保持为一条猜测。
